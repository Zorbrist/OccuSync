## Prerequisites

* Node.js
* npm
* Git
* Docker Desktop

## Run the Backend

```bash
cd backend-OccuSync
npm install
npm run dev
```

Backend:

```text
http://localhost:3000
```

## Run the Frontend

Open a **new terminal**:

```bash
cd frontend-OccuSync
npm install
npm run dev
```

Frontend:

```text
http://localhost:5173
```
